# TypeAnvil showcase

Rendered output from [TypeAnvil](https://github.com/whitelodge-esoteric/typeanvil), a pure-Rust HTML to PDF engine for paged media: `@page`, fragmentation, running headers, footnotes, tables, and tagged PDF.

Site: https://whitelodge-esoteric.github.io/typeanvil-showcase/

Every release tag publishes its showcase documents here, rendered by the release binary at 150 DPI, next to a Prince reference render.

- [Latest](latest/README.md) is a stable link to the newest version.
- [Performance history](perf/README.md)
